# 🐶 Sistema de Cadastro Simplificado para o PetCare+

## 🎯 Objetivo
Esse sistema de cadastro foi feito com o intuito de colocar em prática os conhecimentos adquiridos sobre <strong>GitFlow.</strong>

## 📋 As branchs utilizadas foram:
- <strong>Develop</strong>: Utilizada para criar features a partir dela e integrá-las quando estiverem concluídas.
- <strong>Main</strong>: Código estável.
- <strong>feature/auth</strong>: Criação da tela de login.
- <strong>feature/dashboard</strong>: Criação da tela com as opções "Cadastrar Cliente", "Listar Clientes" ou "Sair".
- <strong>feature/cadastro</strong>: Criação da tela para cadastrar informações pessoais do cliente e o seu respectivo pet.
- <strong>feature/lista</strong>: Criação da tela para a listagem dos clientes.

## 📃 Fluxo de desenvolvimento:
- A branch <strong>develop</strong> foi utilizada como base para a criação de outras features.
- Cada funcionalidade foi desenvolvida em uma branch <strong>feature/*</strong>.
- Após a finalização de cada feature, elas foram integradas à <strong>develop</strong>.
- Ao final do projeto, a branch <strong>develop</strong> foi integrada na <strong>main</strong>.

## ✏️ Tipos de commits:
Durante o desenvolvimento, os tipos mais utilizados por mim foram:
- <strong>feat</strong>: Adicionar nova funcionalidade.
- <strong>style</strong>: Adicionar estilo às telas.
- <strong>chore</strong>: Utilizado para organizar a estrutura do projeto.
- <strong>docs</strong>: Para a documentação do README.

## 👩‍💻 Tecnologias utilizadas:
HTML, CSS e JavaScript.

### 📌 Tela de cadastro
- Na tela de cadastro o funcionário irá preencher as informações pessoais do cliente e do pet. Por questões de simplificação, assumi que cada cliente terá apenas 1 (um) animal de estimação.

### 📌 Tela de Listagem dos clientes
- À medida que novos clientes vão sendo cadastrados, eles serão automaticamente colocadas na lista. Também por questões de simplificação, coloquei apenas as 3 informações principais: Nome do cliente, telefone e nome do pet.
